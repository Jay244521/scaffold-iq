# Keelwell logo files (working name, not trademark-cleared)

| File | Use |
|---|---|
| `keelwell-badge.svg` | Primary badge: Graphite shield, Signal-orange K. App icon, favicon, embroidery, stickers |
| `keelwell-badge-reverse.svg` | On dark backgrounds and packaging bands |
| `keelwell-badge-black.svg` | One-color printing, deboss, laser etch |
| `keelwell-lockup-light.svg` / `-dark.svg` | Badge + wordmark for web, documents and packaging |

- Colors: Graphite #1F2A36 · Signal #E8671B · Sand #E9E2D6 · Steel #8A97A5 · Kraft board.
- Fonts: Barlow Condensed ExtraBold (headlines) and Inter (body), both free Google Fonts. The lockup SVGs use live text, so convert it to outlines before sending to a printer.
- Minimum sizes: badge 16 px / 6 mm; full lockup 120 px / 30 mm wide.

The full logo sheet and packaging designs live on the design canvas. Its source files are in `../packaging-source/`.
